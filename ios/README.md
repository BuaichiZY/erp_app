# ERP iOS / iPadOS

当前本地版本为 **1.4.5（构建 9）**，原生 SwiftUI，支持 iOS / iPadOS 17 及以上。

## 本地开发

安装 Xcode 和 XcodeGen，在 `ios` 目录执行 `xcodegen generate`，打开 `ERP.xcodeproj`，选择 iPhone 或 iPad 模拟器后运行。项目支持两种设备；设备安装需要 Apple 签名。

在 Mac 上运行 `python3 ios/export-playground.py` 可同步 Swift Playgrounds 工程；Windows 可使用 `ios/export-playground.ps1`。将 `ios/ERP-iPad.swiftpm` 复制到 iPad 文件应用，再用 Swift Playgrounds 打开。

- 模式切换显示“混合”文字，横屏显示完整模式名称。

- 喜欢页使用至少 48 点高的三个明确按钮，切换时取消过期数据写入，并显示加载及失败重试状态。
- 通知从 `data.title` / `data.message` / `data.body` 读取标题正文，按通知类型补齐标题，日期按本地时间格式显示。
- 聊天名片使用聊天页自己的导航状态，避免与根页面争抢呈现；兼容直接或 `match` 包装的聊天详情响应，加载失败时在聊天页提示。
- 登录改成独立全屏页面，横屏为夜景介绍与登录表单双栏，窄窗口为单栏；保留原生邮箱、密码、二步验证码输入及真实 Cloudflare 验证。
- 横屏探索为左侧滑卡与右侧快速预览，共享照片选中状态；竖屏及窄窗口恢复单栏。快速预览直接使用推荐数据，不额外请求完整名片。
- iPad 横屏聊天嵌入主内容区域，保留侧栏和顶部模式栏；iPad 聊天头像直接进入主内容区域的玩家资料页，返回或“发送消息”回到原聊天并保留输入、滚动和路由；iPhone 保留聊天内名片弹窗。
- 永久能量使用切面钻石图标；移除顶部文字切换按钮。
- 内容模式采用 `/config` 的 `appearance` 配色和风格，NSFW 默认紫色深色 / 黄色浅色；亮度支持跟随模式、浅色、深色、跟随系统，与内容模式独立。
- 参考 Safari 网页调整侧栏、浏览入口、详细资料和语言熟练度展示；Playgrounds 源码同步更新。

## 构建 9：侧栏角标与浏览页

- 数字角标设置等宽高的最小尺寸，并禁止横向压缩；单个数字显示为圆形，多位数字按需要扩宽。
- 浏览请求显式使用 `sort=hot`，避免省略排序时进入会员限定的默认排序；会员排序仅展示服务端允许的选项，权限变更后回退热门。
- 对照当前 Safari 浏览页补齐 3:4 卡片、前三项表情反应、在线状态、媒体分级及不可见提示、喜欢/超级喜欢百分比、认证、配对人数、共同意向和批量留言弹幕；iPhone 两列、iPad 竖屏三列、宽屏四列。
- 根据服务端 `hotShuffle` 显示随机热门说明；热门资料仅供浏览，隐藏送出喜欢操作。保留封面大图、照片、留言、表情、检举及封锁等入口。
- 浏览筛选支持六组多选、全身追踪、语音名片、在线及相近时区；在线筛选仅在服务端支持时显示，工具栏显示生效筛选数量。分页保留手动重试，并在末尾出现时自动加载。
- 分离探索与浏览数据，加载失败显示页面内重试，取消或过期请求不弹出错误；关闭资料、旋转或重新显示页面时保留已加载的卡片与列表位置。
